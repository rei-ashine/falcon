## [2.0.0] - 2024-06-14

### Added
- Initial release of Falcon theme for Visual Studio Code
- Complete theme support for all VS Code UI elements
- Syntax highlighting for all major programming languages
- Support for VS Code's built-in terminal colors
- Comprehensive color scheme based on the Falcon palette

### Features
- Dark theme optimized for readability
- Consistent color palette across all UI elements
- Support for editor decorations and highlighting
- Proper contrast ratios for accessibility
- Integration with VS Code's semantic highlighting

### Supported Languages
- JavaScript/TypeScript
- Python
- Ruby
- Go
- C/C++
- Java
- PHP
- HTML/CSS
- JSON/YAML
- Markdown
- And many more...

## Previous Versions

This is the first VS Code extension release. The Falcon color scheme has been available for other applications since 2018.
