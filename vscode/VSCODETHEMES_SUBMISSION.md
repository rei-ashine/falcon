# Direct Submission to vscodethemes.com

## Alternative Publishing Method

If you choose not to publish to the VS Code Marketplace, you can submit directly to vscodethemes.com:

### Steps:

1. **Visit the Submission Page**
   - Go to https://vscodethemes.com/submit

2. **Prepare Theme Information**
   - Theme Name: Falcon
   - Description: A dark, easy on the eyes, fiery color scheme
   - Author: fenetikm
   - Repository: https://github.com/fenetikm/falcon
   - Theme File: `vscode/themes/falcon-color-theme.json`

3. **Upload Theme File**
   - Upload the `falcon-color-theme.json` file
   - Or provide the raw GitHub URL to the theme file

4. **Add Metadata**
   - Tags: dark, orange, blue, professional
   - Category: Dark Themes
   - Screenshots: Upload screenshots of the theme in action

5. **Submit for Review**
   - The vscodethemes.com team will review and publish

### Required Information:
- Theme JSON file
- Theme name and description
- Author information
- Repository link (optional but recommended)
- Screenshots (recommended)

### Screenshots to Include:
- JavaScript/TypeScript code sample
- Python code sample
- CSS/HTML sample
- Overall VS Code interface with the theme

Note: Direct submission may take longer to appear and won't be available in VS Code's built-in theme marketplace.
